## ⚙️ How I Build

I prefer **depth over unnecessary complexity**.

My approach is centered around:

* Understanding the problem before choosing the technology
* Building a clear core system before adding optional components
* Evaluating models and systems with meaningful metrics
* Making architectural decisions explainable
* Keeping implementations reproducible and well documented
* Using advanced technologies only when they materially improve the project

For every substantial project, I aim to understand:

**What am I solving? → Why this approach? → What alternatives exist? → How does it work end to end? → How was it evaluated? → What failed? → What are its limitations? → What would I improve next?**
